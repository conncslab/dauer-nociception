Code description
prepare_sets_polarity_sample.py
•	Build the parameters data frame (all combinations of parameters values – 7^7 = 823,543 rows). Save to csv: "Parameters_combinations_df.csv".  
•	Consider 4 possibilities of inhibitory connections: ASH - AVB, AVB - AVA, A - B, B - A. find all possible combinations of inhibition and excitation (2^4 = 16). Save to pickle file: "Polarity_combinations_sample.pkl". 

find_parameters_polarity_4_connections.py
•	Import 3 files:
	1.	"Parameters_combinations_df.csv" (created in the previous code file). 
	2.	"Polarity_combinations_sample.pkl" (created in the previous code file).
	3.	"41586_2019_1352_MOESM9_ESM.xlsx" – connectivity map (Cook et al, 2019). 
•	Read Cook's connectivity data and narrow for the neurons of interest only. 
•	Combine all combinations of parameters (823,543) and polarity (16), overall- 13,176,688.
•	For every row randomly increase\decrease\leave unchanged each synaptic strength value.
•	Test for each sex two sets of conditions – behavioral and physiological. 
•	Save the results and the adjustments that were done to the connectivity matrices.  
•	Use helper functions from: 
	1.	extract_connectivity_df.py
	2.	supporting_functions.py

read_parameters_polarity_4_connections.py
•	Read the outputs of the previous file (find_parameters_polarity_4_connections.py) and save into 2 csv files:
	1.	"basic_true_par_pol_samp.csv" – rows in which the behavioral conditions are true for the male or the hermaphrodites. 
	2.	"herm_cell_activity_basic_mutual.csv" – rows in which the behavioral conditions are true for the male and the hermaphrodites, in addition, the physiological conditions are true for the hermaphrodites. 
•	Import "Polarity_combinations_sample.pkl" and for each polarity test how many sets were valid, based on the two sets of conditions (behavioral and physiological). Save the result to csv: "valid_sets_per_polarity.csv"
•	Import "Parameters_combinations_df.csv" and simulate a single set for example, from polarity 8 (ASH to AVB is inhibitory and the rest are excitatory). 
•	Plot bar plot for the distribution of values that appeared in valid sets for each polarity combination.
•	Use helper functions from supporting_functions.py

find_parameters_polarity_all_single_flips.py
•	Import 2 files:
	1.	"Parameters_combinations_df.csv" (created in previous code file). 
	2.	"41586_2019_1352_MOESM9_ESM.xlsx" – connectivity map (Cook et al, 2019). 
•	Read Cook's connectivity data and narrow for the neurons of interest only.
•	Identify all chemical synapses for each sex, and create a united list.
•	Subtract from the list synapses that were already tested in the code file: find_parameters_polarity_4_connections.py. Each of the remaining synapses (14), one by one, will be simulated as inhibitory.
•	Combine all combinations of parameters (823,543) and polarity (14), overall- 11,529,602.
•	For every row randomly increase\decrease\leave unchanged each synaptic strength value.
•	Test for each sex two sets of conditions – behavioral and physiological. 
•	Save the results and the adjustments that were done to the connectivity matrices.  
•	Use helper functions from: 
	1.	extract_connectivity_df.py
	2.	supporting_functions.py

find_different_sensory_stimuli_4_connections.py
•	Import 2 files:
	1.	"Parameters_combinations_df.csv" (created in a previous code file).
	2.	"herm_cell_activity_basic_mutual.csv " (created in a previous code file).
•	For all sets that met all behavioral conditions for both sexes and the physiological conditions for the hermaphrodites, test the response for different stimulus strength. For each set (including different parameters and polarity), save the difference in membrane potential between the average activity of A in the last second of the stimulus, to the average activity of B (in the same time points). From the difference infer the direction of the movement for each stimulus.   
•	Use helper functions from supporting_functions.py

supporting_functions.py
This file contains helper functions used in many other files as specified above. 

extract_connectivity_df.py 
This file contains functions for extracting the connectivity data from Cook et al (2019), and organizing it. Few changes are being made to Cook's data:
	1.	We take only neurons of interest. 
	2.	We apply a threshold for strength of chemical synapses.
	3.	We average over neural groups. 
	4.	We ignore connections within a neural group. 
	5.	We transpose Cook's data (for calculation purposes).
